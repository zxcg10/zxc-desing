# zxc-desing

Cursor / agent skill: Apple HIG + Liquid Glass dashboard reskin kit（tokens、chrome、primitives）。

**Only runs when explicitly named** (`zxc-desing` / Liquid Glass reskin). Does not auto-invoke.

## Install

```bash
# Cursor（项目级）
npx skills add zxcg10/zxc-desing -a cursor -y

# 全局
npx skills add zxcg10/zxc-desing -a cursor -g -y
```

Then invoke with `/zxc-desing` or by naming the skill in chat.

SKILL.md
