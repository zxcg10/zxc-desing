# zxc-desing — i18n and fonts

Choose type strategy from `<html lang="...">` (or the active i18n locale).  
**Do not** force English-style uppercase headers onto Chinese UI.

## Detect

| Signal | Strategy |
|--------|----------|
| `lang="zh"` / `zh-CN` / `zh-Hans` / primary UI copy is Chinese | **Chinese** |
| `lang="en"` / primary UI copy is English | **English** |
| Bilingual or switchable locale | Headers / eyebrows follow **current** locale; CSS may use `:lang(zh)` / `:lang(en)` |

```bash
rg -n 'lang=|i18n|locale|zh-CN' index.html src --glob '*.{html,tsx,jsx,vue,ts,js}' | head -40
```

## Chinese strategy

| Element | Rule |
|---------|------|
| Table / column headers | **No** `uppercase` / `text-transform: uppercase` |
| Size / weight | `11px`, `font-normal`, `text-muted-foreground`; **lighter** than cells |
| Tracking | Near `0` / slight negative; avoid `tracking-wider` spreading CJK |
| Titles | `font-display` + slight negative tracking (e.g. `-0.02em`) |
| Numbers | Always `tabular-nums` / `tnum` (language-agnostic) |

## English strategy

| Element | Rule |
|---------|------|
| Secondary / eyebrow / table headers | **Allow** `uppercase` + `tracking-wider` (or `0.04em–0.08em`) for hierarchy |
| Weight | Headers still light (≤ medium); never heavier than body |
| Main titles | Slightly tight tracking OK; sentence case over ALL-CAPS titles |
| Numbers | Same `tabular-nums` |

## Optional CSS

```css
/* Chinese: kill uppercase headers */
:lang(zh) .table-head,
:lang(zh-CN) .table-head,
html[lang^="zh"] thead th {
  text-transform: none;
  letter-spacing: 0;
  font-size: 11px;
  font-weight: 400;
  color: var(--muted-foreground);
}

/* English: secondary headers may uppercase */
:lang(en) .table-head,
html[lang^="en"] thead th {
  text-transform: uppercase;
  letter-spacing: 0.06em;
  font-size: 11px;
  font-weight: 500;
  color: var(--muted-foreground);
}
```

## Font stack

Always use the system stack from tokens (SF / Segoe / PingFang / Microsoft YaHei /
Noto Sans SC…).  
**Do not** add webfont dependencies for a reskin. **Do not** copy licensed SF Pro files.

- Latin webfont preload **does not** replace CJK; Chinese UI must keep system CJK fallbacks.  
- Tofu glyphs in headless / minimal Linux = **missing fonts in the environment**, not a
  token/optics failure. Critique may note “screenshot host has no CJK.”

## Agent behavior

1. Read `html lang` / i18n config before changing Table / Badge / eyebrow styles.  
2. On Chinese products, sweep and remove mistaken `uppercase`.  
3. On English products, keep reasonable uppercase secondary styles unless they fight card titles.  
4. State in the reply: `lang strategy: zh|en|mixed`.
